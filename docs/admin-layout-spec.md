# 仕様メモ：管理画面のレイアウト（admin-layout）

- 実装プロンプト：`docs/prompt/admin-layout.md`
- 実装完了日：2026-11-06
- デザイン案：https://claude.ai/artifact/9hupa8RCeCi7P2h5vz1ZZi

## A. 概要

**目的・解決する課題**

見本のサイトの管理画面を、プレゼンで見せられる、レスポンシブで今風の見た目にする。色は今後も検討するので、変数で一括して変えられる形にする。各画面の中身のマークアップは変えず、レイアウトと共通の CSS だけで見た目を変えた。

**変えたこと**

- ヘッダーとサイドメニューを新しいデザインにした。色は CSS 変数で持ち、`<html data-theme="navy">` で組み合わせを選ぶ。本文の地は白で、ヘッダーにはメニューと同じ系統の薄い色を付ける
- 見本のサイトのヘッダーに、色の組み合わせと文字の大きさを切り替えるプルダウンを置いた
- サイドメニューは、広い画面で固定表示とアイコン表示を切り替える。アイコン表示では、マウスを乗せると重なって開く。グループの見出しで開閉し、1つを開くとほかは閉じる
- 本文を横幅の95%にした。文字の大きさは小（90%）・中（100%。既定）・大（110%）から選べる
- Bootstrap のボタン・入力欄・表・カード・ページ送りを、変数の色と角の丸みに合わせた

**変更したファイル**

| 場所 | ファイル |
|---|---|
| フレームワーク | `resources/css/admin.css`・`resources/js/admin_layout.js`（新規）、操作ログの画面（`content-width` を外した） |
| 見本のサイト | `resources/views/layouts/admin.blade.php`・`resources/views/admin/_menu.blade.php`・`vite.config.js` |
| 文書 | 利用ガイド（0章「管理画面の見た目」）・名前の一覧・`check_latest.sh` |

## B. 実装仕様

**色の組み合わせ**

| 名前 | ヘッダーの地 | サイドメニューの地 | ボタン |
|---|---|---|---|
| `navy`（既定） | `#e4ebf4` | `#4a6a94` | `#4f6fa8` |
| `green` | `#e3efe7` | `#4a7f61` | `#2a7d40` |
| `orange` | `#f6e9e1` | `#a95c33` | `#b3562a` |
| `rose` | `#f5e6e8` | `#a24d5a` | `#b04a57` |
| `light` | `#dde6f4` | 白 | `#4f6fa8` |

「ボタン」は、選んでいる項目やページ送りに使う組み合わせの色（`--nb-accent`）。`btn-primary`・`btn-outline-primary` は、組み合わせによらず同じ青（`--nb-primary`、`#1a73e8`。白い文字との明るさの差が4.5:1）。本文の地は、どれも白。

枠線は、カードと表が `--nb-border`（`#d0d6e0`）、入力欄・プルダウン・チェックボックスが `--nb-input-border`（`#8c95a3`。白い地との明るさの差が3:1）。組み合わせごとに変わるのは変数の値だけ。`data-theme` を書かなければ `navy`。

**色の切り替え**

見本のサイトのヘッダーのプルダウン（`data-nb-theme-select`）で選ぶと、`<html>` の `data-theme` を替え、`neobit.admin.theme` に覚える。文字の大きさ（`data-nb-font-size-select`）も同じ形で、`data-font-size` を替え、`neobit.admin.fontSize` に覚える。次の画面では、`<head>` の中の短いスクリプトが、画面を出す前に当てる。知らない名前は当てない。色を決めたサイトでは、レイアウトからプルダウンを消す。

**メニュー**

- グループは `<details>`・`<summary>` で、同じ `name="nb-menu"` を付ける。1つを開くとほかが閉じるのはブラウザーの働きで、JavaScript は使わない（Chrome・Edge 120、Safari 17.2、Firefox 130 以降。古いブラウザーでは複数開けるだけ）
- 今の画面のグループ（`.is-current`）を開いて出す。グループの開閉は覚えない。開くのはいつも1つで、画面を移ると今の画面のグループが開くため
- 表示の切り替え（`neobit.admin.sidebar`）を `localStorage` に覚える
- 前に選んだ表示は、レイアウトの中の短いスクリプトが、画面を出す前に当てる。`admin_layout.js` は画面を出した後に読まれ、そこで当てると一瞬だけ前の表示が見えるため
- アイコン表示で開く動きは CSS の `:hover`・`:focus-within` で行う。キーボードで入っても開く
- 狭い画面（992px 未満）は、Bootstrap の `offcanvas-lg` で左から引き出す

**本文の幅**

`.nb-content` は横幅の95%。`content-width` は最大幅（既定は無し）として残した。操作ログの画面は、広げるために `1200px` を書いていたが、95%の方が広いので外した。

## C. 前提・依存

- パッケージの追加・更新は無い。Bootstrap 5.3（CDN）のまま
- 書体は端末の日本語の書体。外から読み込まない
- `vite.config.js` に `admin.css`・`admin_layout.js` を足したので、サーバーで `npm run build` が要る

## D. 設計判断とトレードオフ

| 判断 | 選んだもの | 選ばなかったもの |
|---|---|---|
| CSS と JS の置き場所 | フレームワーク | 案件の側：案件ごとに写すことになり、色の変数の名前がそろわない |
| 色の選び方 | `data-theme` の属性と CSS 変数 | Sass で組み合わせごとに作る：ビルドの手間が増え、案件で変数を上書きできない |
| グループの開閉 | `<details>` に同じ `name` | Bootstrap の collapse：JavaScript が要り、マークアップも増える。開閉を覚える：1つだけ開く形では意味が無い |
| 色の切り替え | ヘッダーのプルダウンで、ブラウザーだけに覚える | 設定に保存する：ほかの人の画面まで変わる。見比べるためのもので、色はレイアウトの `data-theme` で決める |
| 文字の大きさ | `<html>` の `data-font-size` で90%・100%・110% | 本文だけ `0.9em`：Bootstrap の部品が rem で大きいまま残る |
| 各画面の中身 | 直さない | 検索の枠や必須の目印も案に合わせる：ナビを確かめてから考える |

## E. 課題・懸念点

| 重要度 | 内容 |
|---|---|
| 低 | 各画面の中身は Bootstrap のままなので、検索の枠や編集画面の目印は、案の見た目とは違う |
| 低 | 色の組み合わせは、まだ検討の途中。値は `admin.css` の頭で変えられる |
| 低 | 企業会員と訪問者の画面は、今までの見た目のまま |

## F. セキュリティ・権限・データ整合性の注意

- `localStorage` に覚えるのは、メニューの表示と色の組み合わせと文字の大きさだけ。個人の情報や、権限に関わる値は置かない
- メニューの項目と権限の扱い（管理者だけの項目を出さない）は、今までと変えていない
